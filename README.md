# Pixi.js Test Game

Небольшой проект-игра на [Pixi.js](https://pixijs.com/).

## Стек

- Pixi.js
- JavaScript / TypeScript
- Node.js (для локального запуска и сборки)

## Быстрый старт

1. Установите зависимости:

```bash
npm install
```

2. Запустите проект в режиме разработки:

```bash
npm run dev
```

3. Сборка production-версии:

```bash
npm run build
```

4. Локальный предпросмотр сборки:

```bash
npm run preview
```

## Структура (пример)

```text
src/        исходный код игры
assets/     текстуры, спрайты, аудио
public/     статические файлы
```

## Примечания

- Убедитесь, что установлен Node.js LTS версии.
- Если в проекте используются другие скрипты, обновите команды в этом README под ваш `package.json`.
